# Математикийн ажлын хуудас (6–12-р анги)

Сурагч цахимаар бөглөж шууд шалгуулдаг, багш A4 PDF болгон хэвлэдэг математикийн ажлын хуудасны сайт.

- 6–12-р анги, сургалтын хөтөлбөрийн агуулгаар бүлэглэсэн 200 гаруй сэдэв
- Тест, задгай, холимог хэлбэр; «Мэдлэг, ойлголт», «Чадвар», «Хэрэглээ» түвшин
- Сонгох (тест) ба задгай даалгаврын тоог тус тусад нь (0–20) сонгоно.
- Даалгавар бүр шинээр үүснэ. Ижил кодоор (жишээ нь `9-5-1-10+5-2024` = 10 сонгох, 5 задгай) ижил хуудсыг дахин гаргана. Хуучин `9-5-1-10-2-2024` хэлбэрийн код ч ажиллана.
- Томьёо KaTeX-ээр, PDF нь хариултын түлхүүр болон А/Б/В хувилбартай
- Сервер, өгөгдлийн сан, build шаардлагагүй. Цэвэр статик сайт.

## Хавтасны бүтэц

```
index.html                 Хуудасны бүтэц (HTML)
css/style.css              Загвар (CSS)
js/config.js               Тохиргоо: дүн цуглуулах хаяг (RESULTS_URL)
js/app.js                  Хуудасны логик: сонголт, шалгах, PDF, сурагчийн горим
js/results.js              Дүн илгээх, багшийн «Дүн» хэсэг
apps-script/Code.gs        Google Sheets-д дүн хадгалах скрипт
js/generators.js           Даалгавар үүсгэгч (сэдэв бүрийн бодлого, хариу)
js/figures.js              Геометрийн бодлогын зураг (SVG) үүсгэгч
js/mathfmt.js              Бичвэрийг KaTeX томьёо болгох хөрвүүлэгч
vendor/katex/              KaTeX 0.16.11 (JS, CSS, фонт)
vendor/html2pdf.bundle.min.js   PDF үүсгэгч
vendor/qrcode.js           QR код үүсгэгч
favicon.svg                Хөтчийн табын тэмдэг
render.yaml                Render-ийн тохиргоо
```

## Сурагчдад цахимаар өгөх

1. Анги, сэдэв, хэлбэр, түвшин, даалгаврын тоогоо сонгоно.
2. Зүүн талын **«Сурагчдад цахимаар өгөх»** хэсэгт:
   - **Холбоос хуулах** дарж Messenger групп, Teams, Google Classroom-д буулгана, **эсвэл**
   - **QR кодыг самбарт томоор гаргах** дарж проектороор харуулна. Сурагчид утасныхаа камераар уншуулна.
   - **Гүйцэтгэх хугацаа** (5–90 минут эсвэл хязгааргүй) сонгоно. Хугацаатай үед сурагч нэрээ бичээд «Эхлэх» дарахад тоолуур эхэлж, хугацаа дуусахад хариу автоматаар шалгагдаж илгээгдэнэ. Хуудсыг дахин ачаалсан ч цаг шинээр эхлэхгүй, нэг төхөөрөмжөөс дахин илгээх боломжгүй.
   - Шалгасны дараа сурагчид зөв хариугаа харах эсэхийг **«Шалгасны дараа зөв хариуг харуулах»** сонголтоор шийднэ.
3. Сурагч холбоосыг нээхэд зөвхөн ажлын хуудас гарна (тохиргооны хэсэг харагдахгүй). Нэр, бүлгээ бичиж бөглөөд **Шалгах** дарна.
4. Шалгасны дараа хариу түгжигдэнэ. Дүн **автоматаар** багшийн Google Sheets хүснэгтэд бичигдэж, сурагчид «Дүн багшид хүрлээ ✓» гэж харагдана (доорх «Дүн цуглуулах»-ыг нэг удаа тохируулсан бол). Нөөц болгож **«Мессежээр илгээх»** товч бас бий.

## Дүн цуглуулах (Google Sheets, үнэгүй) — нэг удаа тохируулна

Сурагчдын дүн багшийн өөрийн Google бүртгэл дэх хүснэгтэд хадгалагдана. 100 гаруй сурагч зэрэг илгээхэд асуудалгүй.

**А. Хүснэгт ба скрипт үүсгэх**
1. https://sheets.google.com → **Хоосон хүснэгт** үүсгээд «Математик дүн» гэж нэрлэнэ.
2. Цэснээс **Extensions (Өргөтгөл) → Apps Script** дарна.
3. Нээгдсэн цонхны `Code.gs` доторх бүх бичвэрийг устгаад, энэ хавтасны **`apps-script/Code.gs`** файлын агуулгыг бүтнээр нь хуулж тавина.
4. Эхний мөрүүдийн `const TEACHER_KEY = 'ЭНИЙГ-СОЛИНО-УУ';`-г өөрийн нууц үгээр солино (жишээ нь `'Math-2026-Bat'`). Энэ нь зөвхөн багшийн «Дүн» хэсэгт нэвтрэх нууц үг.
5. 💾 **Save (Хадгалах)** дарна.

**Б. Вэб апп болгон байршуулах**
1. Баруун дээд **Deploy → New deployment** дарна.
2. ⚙ дүрсээс **Web app** сонгоно.
3. **Execute as: Me (өөрийн имэйл)**, **Who has access: Anyone** гэж тохируулна.
4. **Deploy** → Google зөвшөөрөл асуухад **Authorize access** → өөрийн бүртгэлийг сонгоно → «Google hasn't verified this app» гарвал **Advanced → Go to … (unsafe)** → **Allow**. (Энэ нь таны өөрийн скрипт тул аюулгүй.)
5. Гарсан **Web app URL**-ийг (`https://script.google.com/macros/s/…/exec`) хуулна.

**В. Сайтад холбох**
1. GitHub дээр репогоо нээгээд **`js/config.js`** файл → ✏️ (Edit) дарна.
2. `RESULTS_URL: ''` хэсгийн хашилтан дотор хуулсан хаягаа буулгана:
   `RESULTS_URL: 'https://script.google.com/macros/s/XXXX/exec'`
3. **Commit changes** дарна. 1–2 минутын дараа Render сайтыг шинэчилнэ.

**Г. Дүн харах**
- Сайтын **«Дүн»** таб → нууц үгээ оруулна → код бүрийн жагсаалт гарна (сурагчийн тоо, дундаж хувь).
- Кодыг дарахад: сурагч бүрийн оноо, хувь, зарцуулсан минут, огноо, даалгавар бүрийн зөв/буруу (ногоон/улаан цэг), **даалгавар бүрийн гүйцэтгэлийн график** (аль даалгаврыг ангиараа давтах вэ) гарна.
- **Excel (CSV) татах** товчоор дүнг татаж, дүнгийн дэвтэртээ оруулна. Мөн Google Sheets-ийн «Дүн» хуудсанд бүх мөр шууд харагдана.
- Нэг сурагч дахин бөглөвөл «Оролдлого 2» гэж тэмдэглэнэ. «Зөвхөн эхний оролдлого» сонголтоор эхний дүнг л харуулна.

> Скриптийн кодыг өөрчилсөн бол **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** хийнэ (хаяг өөрчлөгдөхгүй).
> Аюулгүй байдал: дүнг зөвхөн нууц үгтэй багш харна. Хэн нэгэн холбоосыг мэдвэл хуурамч мөр нэмэх боломжтой тул сурагчийн холбоосыг зөвхөн ангидаа хуваалцана уу.

### Ангийн дүнгийн хүснэгт
«Дүн» хэсэгт нэвтэрмэгц ангийн хүснэгт нээгдэнэ. Мөрөнд сурагчид, баганад тухайн ангийн нэгжүүд байрлана. Нүд бүрт гурван түвшний сүүлийн дүн харагдана: мэдлэг, ойлголт (М), чадвар (Ч), хэрэглээ (Х).
- **Анхаарах сурагчид:** аль нэг нэгжийн сүүлийн оролдлогодоо 50%-иас бага авсан, эсвэл дүн нь 15-аас дээш хувиар буурсан сурагчид. «Суурь мэдлэг дутуу» гэсэн тэмдэг нь мэдлэг, ойлголтын түвшинд 50%-иас бага авсныг заана.
- **Давтлагын холбоос:** сул нэгж дээр дарахад тухайн нэгж, түвшний шинэ давтлагын хуудасны холбоос хуулагдана (5 сонгох + 5 задгай). Түүнийг сурагчдаа илгээнэ.
- **Ангиараа давтах нэгж:** ангийн дундаж 60%-иас бага байгаа нэгж, түвшин.
- Сурагчийн нэр дээр дарахад тухайн сурагчийн бүх ажил, нэгж бүрийн ахиц харагдана. Анги, бүлгээр шүүж, Excel (CSV) хэлбэрээр татаж болно.
- Сурагчийг нэр, бүлгээр нь таньдаг (том, жижиг үсэг, илүү зай хамаарахгүй). Сурагчид нэр, бүлгээ байнга ижил бичвэл түүх нь тасрахгүй.
- Code.gs-ийн шинэ хувилбар (v3) бүх дүнг нэг хүсэлтээр өгдөг тул хүснэгт хурдан ачаална. Хуучин хувилбар ч ажиллана, гэхдээ код бүрийг тусад нь татдаг тул удаан.

### Түвшнээр ахих зам (сурагчид)
Сурагч ажлын хуудсаа шалгуулсны дараа «Мэдлэг, ойлголт → Чадвар → Хэрэглээ» гэсэн шат харагдана.
- **80%-иас дээш авбал** дараагийн түвшин нээгдэж, «… түвшинд шилжих» товч гарна. Ижил сэдэв, ижил тооны даалгавартай шинэ хуудас үүснэ.
- **80%-д хүрэхгүй бол** «Шинэ хувилбар бөглөх» товч гарна. Ижил түвшин, өөр тоотой хуудас үүснэ.
- Хугацаа болон зөв хариу харуулах тохиргоо дараагийн хуудсанд ч хэвээр үлдэнэ. Бүх оролдлогын дүн багшийн хүснэгтэд ирж, ангийн хүснэгтэд нэгж, түвшнээрээ харагдана.
- Сурагчийн давсан түвшнүүд тухайн төхөөрөмж дээр нэр, бүлгээр нь хадгалагдана.

### Алхамчилсан бодолт
Даалгаврыг шалгасны дараа алдсан эсвэл хоосон даалгавар бүрийн доор тайлбар гарна.
- **Бодох арга:** тоо агуулаагүй ерөнхий заавар. Бүх 228 сэдэвт бий бөгөөд сурагчид үргэлж харагдана. Текстийг `js/methods.js` файлд засаж болно.
- **Бодолтыг харах:** тухайн даалгаврын тоогоор алхам алхмаар бодсон бодолт ба зөв хариу. 6–9-р ангийн бүх сэдэв, түвшинд, мөн 10–12-р ангийн түгээмэл сэдвүүдэд бий (нийт 378 сэдэв-түвшин).
- Сурагчид тоон бодолт зөвхөн багш холбоос үүсгэхдээ «Шалгасны дараа зөв хариуг харуулах»-ыг сонгосон үед харагдана. Нэг холбоостой сурагчид ижил тоотой даалгавар авдаг тул ингэж хариу тарахаас сэргийлнэ. Багшийн горимд бодолт үргэлж харагдана.

### Урам зориг (сурагчид)
- **Амжилтыг тэмдэглэх:** зөв хариулт бүр «гялсхийнэ». 80%-иас дээш авахад шохойн тоос, од цацарна. Урамшууллын үг хүүхдийн өөрийн өмнөх дүнтэй харьцуулж гарна, жишээ нь «Өмнөх хамгийн сайн дүнгээсээ 30 хувиар ахилаа!».
- **Миний ахиц:** сурагчийн мөрөнд «★ N од · Миний ахиц» товч гарна. Түүнийг дарахад ангийн оддын зураг, Монгол аялал, тэмдгүүд нээгдэнэ. Оддын зурагт сэдэв бүрт гурван од бий бөгөөд түвшинг 80%-иас дээш дүнтэй давахад нэг од асна.
- **Монгол аялал:** цуглуулсан одны тоогоор Улаанбаатараас Баянзаг хүртэлх 10 буудлыг дамжина.
- **Тэмдэг:** 11 тэмдэг бий. Оноо биш хичээл зүтгэлийг шагнана: алдаанаас суралцах, тэвчээр, дараалсан өдрүүд гэх мэт.
- **Дурсамж:** нэг сэдвийн гурван түвшнийг давсан сурагч нэр бүхий дурсамж (A4, PDF) татна.
- **Өдрийн бодлого:** «Сурагчдад цахимаар өгөх» хэсгийн «Өдрийн бодлогын холбоос хуулах» товч. Холбоос нь `#d-9` хэлбэртэй бөгөөд бодлого өдөр бүр автоматаар солигдоно. Өдрийн бодлогын дүн ангийн дүнгийн хүснэгтэд тооцогдохгүй.
- Ахиц, тэмдэг сурагчийн төхөөрөмж дээр нэр, бүлгээр нь хадгалагдана.

### Сэжүүр ба алдааны зөвлөгөө
- Шалгахаас өмнө даалгавар бүрийн дор «Сэжүүр авах» товч гарна. Дарахад хариуг хэлэлгүйгээр бодох аргыг эсвэл бодолтын эхний алхмыг харуулна. Сэжүүр авсан даалгаврын дугаар багшийн хүснэгтийн «Сурагчийн хариу» баганад `[Сэжүүр: 2, 5]` хэлбэрээр бичигдэнэ.
- Буруу хариултын төрлөөр зөвлөгөө гарна: тэмдэг, 10 дахин, 2 дахин, урвуу тоо, тоймлолт, утгын байр солих гэх мэт. Багшийн «Код бүрээр» дэлгэрэнгүй хэсэгт ангийн «Түгээмэл алдаа» нэгтгэгдэж харагдана.

### Самбарын горим
Багшийн «Цахимаар бөглөх» хэсгийн «Самбарт гаргах» товч. Даалгавруудыг проектор дээр нэг нэгээр нь том үсгээр гаргана. 1–5 минутын цаг тавьж, «Хариу», «Бодолт» товчоор хариу, бодолтыг харуулна. Гарын товчлуурууд: ← → (өмнөх, дараах), зай (хариу), B (бодолт), Esc (гарах).

### Түвшнээр бүлэгт хуваах
«Дүн → Код бүрээр → (код)» дэлгэрэнгүй хэсэгт сурагчид дүнгээрээ гурван бүлэгт хуваагдана: 50%-иас доош бол мэдлэг, ойлголт, 50–79% бол чадвар, 80%-иас дээш бол хэрэглээ. Бүлэг бүрийн холбоосыг нэг товчоор хуулна. Аль ч ажлыг оношлох тест болгон ашиглаж болно.

### Ангийн хамтын зорилго (Code.gs v4 шаардлагатай)
«Дүн → Ангийн хүснэгт» хэсгийн доод талд бүлгийн зорилго тавина, жишээ нь «7б: 500 зөв даалгавар». Зорилго тавьснаас хойш тухайн бүлгийн сурагчдын зөв бодсон даалгаврын нийлбэр тоологдоно. Сурагч бүлгээ бичмэгц ахиц нь дэлгэц дээр нь гарна. Сурагчид зөвхөн ангийн нийт тоог хардаг тул хэний нэр ч ил гарахгүй.

### Эцэг эхэд тайлан
«Дүн → Ангийн хүснэгт»-ийн «Эцэг эхэд тайлан (бүгд, PDF)» товч дарахад сурагч бүрд нэг хуудас тайлан гарна. Сурагчийн нэр дээр дарахад зөвхөн тэр сурагчийн тайланг татаж болно. Тайланд нэгж, түвшин бүрийн дүн, сайн эзэмшсэн, анхаарах сэдвүүд багтана. Мөн гэртээ давтах давтлагын хуудасны QR код орно.

### Интернэтгүй ажиллах
Сайтыг нэг удаа нээхэд файлууд нь төхөөрөмж дээр хадгалагдана (`sw.js`, `manifest.webmanifest`, `icons/`). Ингэснээр интернэтгүй үед ч сайт нээгдэнэ. Android Chrome дээр толгой хэсэгт «Утсандаа суулгах» товч гарна. Интернэтгүй үед шалгуулсан дүн төхөөрөмж дээр хадгалагдаж, холболт орж ирэхэд автоматаар илгээгдэнэ.

### Олон багш ашиглах (багш бүр өөрийн хүснэгттэй)
Нэг сайтыг хэдэн ч багш ашиглаж болно. Багш бүр өөрийн Google хүснэгт, Apps Script-ийг (дээрх «Дүн цуглуулах» заавар) үүсгээд дараах алхмыг хийнэ:
1. Сайтын зүүн талын **«Дүн хүлээн авах хүснэгт»** хэсэгт өөрийн `…/exec` хаягаа оруулаад «Хадгалах» дарна. Хаяг тухайн багшийн хөтөч дээр хадгалагдана.
2. Үүний дараа «Холбоос хуулах», QR код, өдрийн бодлого, бүлгийн холбоос, тайлангийн QR бүгд `@…` тэмдэгтэй болж, тэр багшийн хүснэгтийг заана. Сурагчийн дүн зөвхөн холбоос өгсөн багшид очно.
3. «Дүн» хэсэгт өөрийн `TEACHER_KEY`-ээр нэвтэрнэ.

`js/config.js` дахь хаяг нь хэн ч өөрийн хаягаа оруулаагүй үед ашиглагдах үндсэн хаяг юм.

### Ангийн нэрсийн жагсаалт (Code.gs v5)
«Дүн → Ангийн хүснэгт» хэсгийн доод талд бүлэг бүрийн нэрсийг оруулна. Мөр бүрт нэг нэр бичнэ, Excel-ээс хуулж тавьж болно.
- Сурагч бүлгээ бичмэгц нэрээ жагсаалтаас сонгоно. Ингэснээр нэрийн зөрүүнээс болж түүх тасрахгүй. Жагсаалтад нэр нь байхгүй сурагч «Миний нэр жагсаалтад алга» сонгоод гараар бичнэ.
- Ангийн хүснэгтэд **«Нэг ч ажил илгээгээгүй сурагчид»**, кодын дэлгэрэнгүй хэсэгт **«Энэ ажлыг илгээгээгүй сурагчид»** гарна.
- Жагсаалтыг холбоостой хэн ч харж болох тул нэрийг «Ану О.» гэх мэт товч бичихийг зөвлөж байна.

### Улирал архивлах (Code.gs v6)
Улирал дуусахад «Дүн → Ангийн хүснэгт»-ийн доод талын «Одоогийн дүнг архивлах» товчийг дарна. Бүх дүн «Архив: <нэр>» нэртэй тусдаа хуудас руу хуулагдаж, «Дүн» хуудас хоосорно. Ингэснээр сайт дахин хурдан ачаалагдана.
- Архивласан дүнг «Харах» товчоор сайтаас нээнэ. Ангийн хүснэгт, код бүрийн дүн, тайлан бүгд ажиллах ч зөвхөн харах горимтой.
- Нэрсийн жагсаалт, хамтын зорилгын тохиргоо хэвээр үлдэнэ.
- Архивлахын өмнө Excel (CSV) хуулбар татаж авахыг зөвлөж байна.

## 2. GitHub-д байршуулах

### А арга: хөтчөөр (git суулгах шаардлагагүй)

cd matematik-ajlyn-khuudas

## 3. Render дээр нийтлэх (үнэгүй статик сайт)

1. https://render.com руу **GitHub-ээр** нэвтэрнэ.
2. **New +** → **Static Site** дарна.
3. `matematik-ajlyn-khuudas` репог сонгоод **Connect** дарна.
4. Тохиргоо:
   - **Name:** `matematik-ajlyn-khuudas`. Энэ нэр хаяг болно: `https://matematik-ajlyn-khuudas.onrender.com`.
   - **Branch:** `main`
   - **Root Directory:** хоосон
   - **Build Command:** хоосон, эсвэл `echo ok`
   - **Publish Directory:** `.`
5. **Create Static Site** дарна. 1–2 минутын дараа сайт нээгдэнэ.

> Өөр арга: Render-д **New +** → **Blueprint** сонгоод репогоо холбовол `render.yaml` файлаас тохиргоог автоматаар уншина.

Render-ийн статик сайт үнэгүй бөгөөд "унтах" горимгүй тул шууд нээгдэнэ.

### Өөрийн домэйн (сонголттой)

Render → сайт → **Settings → Custom Domains → Add**. Жишээ нь `math.сургууль.mn` гэж оруулаад Render-ийн зааврын дагуу домэйн бүртгэгч дээрээ CNAME бичлэг нэмнэ. SSL (https) автоматаар идэвхжинэ.

## 6. Сайтыг өөрчлөх

- **Сургуулийн нэр:** сайт дээрх «Сургуулийн нэр» талбарт бичихэд хуудасны толгойд гарна.
- **Өнгө, фонт:** `css/style.css` файлын эхэнд байгаа `:root{ --… }` хувьсагчдыг солино.
- **Шинэ сэдэв нэмэх:** `js/generators.js` дотор тухайн ангийн хэсэгт байгаа `a8(...)`, `a9(...)` загварыг хуулж, `gen(r, l)` функцэд бодлого болон зөв хариуг буцаана. `r.i(a, b)` нь санамсаргүй бүхэл тоо өгнө. `l` нь түвшин (1–3).
