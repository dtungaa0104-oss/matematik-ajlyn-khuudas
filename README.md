# Математикийн ажлын хуудас (6–12-р анги)

Сурагч цахимаар бөглөж шууд шалгуулдаг, багш A4 PDF болгон хэвлэдэг математикийн ажлын хуудасны сайт.

- 6–12-р анги, сургалтын хөтөлбөрийн агуулгаар бүлэглэсэн 200 гаруй сэдэв
- Тест, задгай, холимог хэлбэр; суурь, дунд, ахисан түвшин
- Даалгавар бүр шинээр үүснэ. Ижил кодоор (жишээ нь `9-5-1-10-2-2024`) ижил хуудсыг дахин гаргана.
- Томьёо KaTeX-ээр, PDF нь хариултын түлхүүр болон А/Б/В хувилбартай
- Сервер, өгөгдлийн сан, build шаардлагагүй. Цэвэр статик сайт.

## Хавтасны бүтэц

```
index.html                 Хуудасны бүтэц (HTML)
css/style.css              Загвар (CSS)
js/app.js                  Хуудасны логик: сонголт, шалгах, PDF
js/generators.js           Даалгавар үүсгэгч (сэдэв бүрийн бодлого, хариу)
js/mathfmt.js              Бичвэрийг KaTeX томьёо болгох хөрвүүлэгч
vendor/katex/              KaTeX 0.16.11 (JS, CSS, фонт)
vendor/html2pdf.bundle.min.js   PDF үүсгэгч
favicon.svg                Хөтчийн табын тэмдэг
render.yaml                Render-ийн тохиргоо
```

## 1. Компьютер дээрээ туршиж үзэх

Хавтсан дотор терминал нээгээд:

```bash
python3 -m http.server 8000
```

Дараа нь хөтчөөр `http://localhost:8000` хаягийг нээнэ. `index.html`-ийг шууд давхар товшиж нээвэл зарим хөтөч скриптийг хаадаг тул дээрх аргыг хэрэглээрэй.

## 2. GitHub-д байршуулах

### А арга: хөтчөөр (git суулгах шаардлагагүй)

1. https://github.com руу нэвтэрч, баруун дээд **+** → **New repository** дарна.
2. Нэр: `matematik-ajlyn-khuudas`, **Public** сонгоод **Create repository** дарна.
3. Гарч ирсэн хуудсан дээрх **uploading an existing file** холбоосыг дарна.
4. Энэ хавтасны **доторх бүх файл, хавтсыг** (index.html, css, js, vendor, …) чирж оруулна. Хавтсыг өөрийг нь биш, доторх зүйлсийг оруулна.
5. Доор **Commit changes** дарна.

### Б арга: git командаар

```bash
cd matematik-ajlyn-khuudas
git init
git add .
git commit -m "Математикийн ажлын хуудас: анхны хувилбар"
git branch -M main
git remote add origin https://github.com/<ТАНЫ_НЭР>/matematik-ajlyn-khuudas.git
git push -u origin main
```

## 3. Render дээр нийтлэх (үнэгүй статик сайт)

1. https://render.com руу **GitHub-ээр** нэвтэрнэ.
2. **New +** → **Static Site** дарна.
3. `matematik-ajlyn-khuudas` репог сонгоод **Connect** дарна.
4. Тохиргоо:
   - **Name:** `matematik-ajlyn-khuudas`. Энэ нэр хаяг болно: `https://matematik-ajlyn-khuudas.onrender.com`.
   - **Branch:** `main`
   - **Root Directory:** хоосон
   - **Build Command:** хоосон, эсвэл `echo ok`
   - **Publish Directory:** `.`
5. **Create Static Site** дарна. 1–2 минутын дараа сайт нээгдэнэ.

> Өөр арга: Render-д **New +** → **Blueprint** сонгоод репогоо холбовол `render.yaml` файлаас тохиргоог автоматаар уншина.

Render-ийн статик сайт үнэгүй бөгөөд "унтах" горимгүй тул шууд нээгдэнэ.

### Өөрийн домэйн (сонголттой)

Render → сайт → **Settings → Custom Domains → Add**. Жишээ нь `math.сургууль.mn` гэж оруулаад Render-ийн зааврын дагуу домэйн бүртгэгч дээрээ CNAME бичлэг нэмнэ. SSL (https) автоматаар идэвхжинэ.

## 4. Шинэчлэх

GitHub дээрх файлаа засах (эсвэл шинэ файл upload хийх, `git push` хийх) бүрт Render сайтыг **автоматаар** дахин нийтэлнэ.

## 5. Өөр сонголт: GitHub Pages

Репо → **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**. Хаяг нь `https://<ТАНЫ_НЭР>.github.io/matematik-ajlyn-khuudas/` болно.

## 6. Сайтыг өөрчлөх

- **Сургуулийн нэр:** сайт дээрх «Сургуулийн нэр» талбарт бичихэд хуудасны толгойд гарна.
- **Өнгө, фонт:** `css/style.css` файлын эхэнд байгаа `:root{ --… }` хувьсагчдыг солино.
- **Шинэ сэдэв нэмэх:** `js/generators.js` дотор тухайн ангийн хэсэгт байгаа `a8(...)`, `a9(...)` загварыг хуулж, `gen(r, l)` функцэд бодлого болон зөв хариуг буцаана. `r.i(a, b)` нь санамсаргүй бүхэл тоо өгнө. `l` нь түвшин (1–3).

## 7. Асуудал гарвал

| Шинж тэмдэг | Шийдэл |
|---|---|
| Томьёо энгийн текстээр харагдана | `vendor/katex/` хавтас бүтэн орсон эсэхийг шалгана (fonts хавтсанд 20 файл байх ёстой). |
| PDF товч ажиллахгүй | `vendor/html2pdf.bundle.min.js` байгаа эсэх, хөтөч татахыг зөвшөөрсөн эсэхийг шалгана. |
| Render дээр 404 | **Publish Directory** нь `.` байгаа эсэх, `index.html` репогийн үндсэн түвшинд байгаа эсэхийг шалгана. |
